1. Electrum 比特币钱包紧急修复 4.8.3

  • 发生了什么：旧版本中，恶意服务器可扣住用户刚广播的交易，替换成收款信息末 4 位相同的假交易；用户点"加速（RBF）"时签下的是攻击者那笔。4.8.3 之前所有版本受影响。
  • 金额：据 X 新闻汇总，已有用户确认丢币，具体金额无数据。可信度：项目方公告，经转述，原帖未直接核对【不确定】。
  • 来源：X 新闻汇总 · 中文转述

2. Keystone 硬件钱包官网客户资料泄露

  • 10-20 发现官网被未授权访问，10-23 确认第三方经 Shopify API 获取了客户姓名、联系方式、收货信息和订单详情。官方称不涉及银行卡、助记词、私钥和钱包密码，并提醒警惕假客服、假"换新设备"。
  • 金额：不涉及资金，受影响人数无数据。可信度：当事方确认。
  • 来源：吴说

3. X100（以太坊）治理被闪电贷接管，约 475 万 USDT 被转走

  • 安全公司 ExVul 称，攻击者 10-24 22:11（北京时间）用闪电贷在一笔交易中接管 X100 的 Senate 治理，转走 361,800 枚 X，变现约 475 万 USDT 后换成 ETH 分散。
  • 可信度：单家安全公司分析，未查到项目方回应【不确定】。
  • 来源：ExVul

可能受影响的人群

  • 使用 Electrum 4.8.3 以前版本、连接公共服务器的比特币用户，尤其常用"加速"功能的人。
  • Keystone 官网下单客户，可能收到精准钓鱼邮件、短信或假"换新"快递。

通用防护建议

  • Electrum 用户尽快从官网升级到 4.8.3；转账和"加速"前核对完整收款信息，不只看末几位。

  • 钱包 App 和浏览器插件只从官网安装；助记词不进入任何联网设备。
