1. BloomTrading（Solana 交易机器人）用户钱包被盗

  • 据链上监测机构 Onchain Lens，一个疑似盗币钱包已收到 49 名受害者的 9,408 枚 SOL，约 95.4 万美元，最大单笔 1,636 SOL（约 16.6 万美元），最终损失可能更高。
  • 状态：Bloom 称正在调查、其他钱包安全，已临时暂停部分服务。另据 X 新闻汇总，Bloom 将原因归于第三方模块的远程代码执行漏洞并承诺全额赔付【汇总转述，未读到官方原帖】。
  • 可信度：链上监测 + 当事方声明。
  • 来源：吴说 · X 新闻汇总

2. Passport 硬件钱包开发商 Foundation 官方域名被冒用发送钓鱼邮件

  • 初步调查显示源于一个或多个 Cloudflare API 密钥泄露。Foundation 已撤销所有相关密钥并关闭恶意域名，称 Passport 硬件钱包未被入侵，调查仍在进行。
  • 金额：无数据。可信度：当事方声明。
  • 来源：吴说
  • 补充：X 新闻汇总称，2026 年已有多个硬件钱包品牌的官网、电商或邮件等周边系统出问题【汇总说法，未逐一核实】，共同点是周边系统被攻破，而非设备本身。

3. 一则"某主流 DEX 聚合器被利用"的单方指控

  • 10-26 下午，一名低粉丝 X 用户称其链上资产经某主流交易所旗下 DEX 聚合器被转走，并在多个官方账号下刷屏。其提供的交易链接无法在以太坊主网查到；窗口内未见安全机构或平台官方确认。
  • 可信度：单方指控，未核实【不确定】。可能是个人授权或私钥问题，也可能是真实漏洞，目前无法判断。
  • 来源：原帖

可能受影响的人群

  • 使用 BloomTrading 机器人、由其托管或代为签名的 Solana 交易者。
  • Foundation / Passport 的客户和邮件订阅者。
  • INIT 持有人（部分韩国交易所充提受限）。
  • 在 DEX 聚合器上留有长期无限授权的用户。

通用防护建议

  • 交易机器人钱包只放短期要用的小额资金，大额资产留在自己掌控的钱包。
  • 发件域名正确不代表邮件可信；要求点链接升级固件、验证助记词的邮件一律视为诈骗。
  • 断开钱包连接不等于撤销链上授权，定期清理不再使用的无限授权和 NFT 全量授权。
  • 被盗后主动找上门"帮忙追回"的，几乎都是二次诈骗。
